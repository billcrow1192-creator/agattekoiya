# あがってこいや。の言葉のトーン（ハードモードの決まり）

「落ちません。」の逆。やさしい言葉が響かない人に、厳しく伝えて「なにくそ」に火をつける。
**言葉そのものは「落ちません。」と同じ言葉データ（1000語以上）。変えるのは伝え方だけ**（`js/hard.js`）。

## 叩いていいもの（厳しくなければ意味がない）
- 止まっている手、先のばし、言い訳、考えるだけ・学ぶだけで作らない状態
- 例（OK）：「そんなことで成功できるなんて、甘すぎるんじゃない？」「やった気になってるだけじゃないか？」
  「学ぶのはもう十分だ。作れ。」「頭の中の計画は、ゼロと同じだ。出せ。」
- いちばん厳しい締め（`CLOSERS_HARD`）は、気分3以上の日だけ

## 先人の戦歴（`js/data/episodes.js`）
- ハードモードで進んだ人の実話。事実の要約は編集部の言葉で、出典URLを必ずつける
- 管理人が直接聞いた言葉は `heard: true`（例：QASOR「セミナーばっかり行ってもダメ。クリエイトしろ、それがすべてだ！」）
- 気分1〜2の日は「失敗からの逆転」（comeback）だけを出す

## 絶対に叩かないもの
- 人格・見た目・能力・存在・生まれ・過去
- 「死」「殺」「甘え」「クズ」「無能」「価値がない」など、人そのものに向ける言葉（`NG_WORDS`。テストで確かめる）
  「甘すぎる」は考えや計画に向けるので OK、「甘え（ているお前）」は人に向けるので NG

## ゆるめる仕組み
- エネルギー「低い」の日：指令は一つだけ（`LOW_ENERGY`）。気合いで押しつぶさない
- 気分1〜2の日：背中を押す強すぎる言葉（push だけの言葉）、「死」「殺」を含む言葉は出さない
- 「きつすぎる」：その言葉は二度と出さず、その場でゆるめる
- 命に関わる言葉（engine.js の `checkSafety`）：ハードモードを止め、落ち着いた画面で24時間の相談窓口を出す

## 書き方
- 短く、言い切る。「〜しろ」「〜だ」
- 最後は前を向かせる（「あがってこいや。」「明日、取り返せ。」）
- 「やった」には短く認める（ほめちぎらない）

## 言葉の選び方（言葉データの精査 v2.1.1）
- 言葉データは「落ちません。」と共通（1015語）。精査の記録は ochimasen リポジトリの `docs/corpus/v2_1-review.md`
- ハードモードでは `fitsHard()`（`js/hard.js`）で次を外す
  - 伝え方と真逆の言葉（「上がらなくていい」「がんばらない日」「何もしなかった日も」「泣いていい」「あなたのままで大丈夫」など）
  - 行動の芯がない「なぐさめだけ」の言葉。ただしエネルギー「低い」の日は「休む」言葉を使う
- 使える言葉：ふだん817語、エネルギー「低い」の日は892語
